HoverLingua / Support

A little help
getting started.

Most setup issues come down to screen access or language availability. Start here, and email us if you're still stuck.

Your first translation

  1. Run HoverLingua on macOS 26 or newer.
  2. Put Hyvää huomenta! Kiitos. in another app, such as Notes or TextEdit.
  3. Choose Finnish → English. Drag the title bar and resize the window so the sentence sits inside the blue rectangle, on one display.
  4. Click Capture & Translate. Allow Screen Recording access if macOS asks. If macOS requests an app restart, quit and reopen HoverLingua, then capture again.
  5. If the app says models are missing, click Prepare Languages (the download-circle button) and allow Apple's download. Once ready, capture again or choose Translate Text.

The expected translation for this sample is “Good morning! Thank you.” Translation wording can vary with the installed model.

Screen Recording permission

Open System Settings → Privacy & Security → Screen & System Audio Recording. On some versions it is called Screen Recording. Enable Screen Recording access for HoverLingua.

HoverLingua doesn't record audio. The separate System Audio Recording Only list does not grant screen access and does not need to be enabled.

Access is enabled, but capture is still denied

Quit and reopen HoverLingua, then try capturing again. If access is still denied, remove only HoverLingua from the upper Screen & System Audio Recording list. Use + to add HoverLingua from your Applications folder, allow access, then reopen the app.

Languages need preparation, or a pair is unsupported

Use Prepare Languages with an internet connection for the initial download. Downloads are presented and managed by Apple. Supported installed pairs work on device. If a pair is unsupported, a download will not make it available; choose another pair. Vision's recognition languages and Apple's translation languages can differ.

No text was found, or the result looks wrong

Put the whole text inside the selection, choose the matching source language, and increase text size or image clarity. Keep the selection on one display. Protected content may be unavailable. Tables, handwriting, and tilted photos can be less accurate; compare the recognized source with the original before relying on the translation.

Moving, resizing, or reopening the window

Drag the native title bar above the language controls and resize at the edges. Press Command–Return to capture while the overlay is focused. Use File → Show Overlay or Command–Shift–O to reopen it, Command–W to close the active window, and Command–Q to quit.

Translation is taking too long

Cancel the current operation, check whether the selected pair needs model preparation, and retry with a smaller region. If the issue repeats with installed models, send us the app version, macOS version, language pair, and the error category or message. You don't need to include your captured text.
